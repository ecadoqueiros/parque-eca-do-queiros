# Sitio web — Área Natural Protegida Eca do Queiros Este sitio es HTML/CSS/JS plano: **no depende de ninguna plataforma externa** (como Lovable) para poder editarse. Cualquier persona puede abrir estos archivos con un editor de texto (o directamente en GitHub) y cambiarlos. ## Archivos ``` index.html → Inicio (Conócenos) servicios.html → Servicios + inventario del vivero (Google Sheets) anuncios.html → Anuncios/Novedades + embed de Instagram actividades.html → Eventos/Actividades historia.html → Historia/Testimonios mantenimiento.html → Mantenimiento galeria.html → Galería de fotos (sección nueva) css/style.css → Todos los estilos (colores, tipografías, etc.) js/main.js → Solo el menú móvil img/ → Aquí van las fotos reales del parque ``` ## Cómo publicarlo (reemplazando el sitio de Lovable) 1. Entra al repositorio de GitHub del parque (`anp-ecadoqueiros/sitioweb` o como se llame). 2. Sube estos archivos a la raíz del repositorio (puedes arrastrarlos desde la web de GitHub: botón **Add file → Upload files**). 3. Ve a **Settings → Pages** del repositorio y confirma que "Source" apunte a la rama donde subiste los archivos (normalmente `main`, carpeta `/root`). 4. Espera 1-2 minutos y el sitio quedará publicado en la misma dirección de siempre. No necesitas ninguna cuenta externa (como Lovable) para que esto funcione — GitHub Pages es gratis y no se "bloquea" por inactividad. ## Cómo editar contenido (sin saber programar) 1. Abre el archivo `.html` de la sección que quieras cambiar (ej. `servicios.html`). 2. Busca el texto que quieres cambiar — está escrito tal cual, entre las etiquetas (ej. `

Este texto se ve en la página

`). 3. Cambia solo el texto entre las etiquetas, sin borrar los símbolos `< >`. 4. Guarda el archivo y súbelo de nuevo a GitHub (o edítalo directamente en la web de GitHub con el lápiz ✏️ que aparece al ver el archivo). ## Pendientes marcados en el sitio Busca estas señales dentro del sitio — indican qué falta por completar: - Cajas punteadas verdes con **"📸 Foto pendiente"** → reemplazar por una foto real - Etiquetas amarillas **"Falta info"** → reemplazar el texto de ejemplo por información real - Comentarios en el código (``) → instrucciones específicas de qué hacer ahí ## Conectar la tabla de inventario del Vivero (Google Sheets) Instrucciones detalladas dentro de `servicios.html` (búscalas cerca de "INVENTARIO DEL VIVERO").
